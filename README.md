# PostForge

An open-source AI-powered social media planning and content management web application.

## Vision

Help small businesses plan, create, organise and manage social media content from one place.

## Planned Features

- AI-powered monthly content strategies
- Instagram, Facebook and LinkedIn captions
- Content calendar
- Content editing and management
- Content export
- Configurable AI providers
- Self-hosting support

## Project Status

Currently in early development.
